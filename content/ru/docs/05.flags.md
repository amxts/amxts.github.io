Статус: проверено на сервере 2026-09-23 (`hideHud`: задать, `push`,
`includes`, `filter`, очистить; `effects`; `flags`).

Где в Pawn битовая маска, здесь массив имён:

```ts
player.hideHud = ["Money", "Timer"];                          // задать набор
player.hideHud.push("Flashlight");                            // добавить
if (player.hideHud.includes("Money")) ...                     // проверить
player.hideHud = player.hideHud.filter(f => f != "Money");    // убрать
player.hideHud = [];                                          // показать всё

if (player.buttons.includes("Jump")) ...
if (player.flags.includes("OnGround")) ...
player.effects.push("NoDraw");
```

Редактор подсказывает имена и отвергает опечатку:
`Type '"Mony"' is not assignable to type 'HideHud'. Did you mean '"Money"'?`

Убрать флаг — присвоить отфильтрованный массив: `pop` и `splice` назад на
игрока не пишут, `push` — пишет.

## Свойства-флаги

| свойство | у кого | имена |
| --- | --- | --- |
| `flags` | `Entity` | `EntityFlag`: `OnGround`, `Client`, `InWater`, `Fly`, `FakeClient`, … |
| `effects` | `Entity` | `Effect`: `NoDraw`, `DimLight`, `BrightLight`, `MuzzleFlash`, … |
| `buttons`, `oldButtons` | `Entity` | `Button`: `Attack`, `Jump`, `Duck`, `Forward`, `Reload`, `Attack2`, … |
| `hideHud`, `clientHideHud` | `Player` | `HideHud`: `Weapons`, `Flashlight`, `All`, `Health`, `Timer`, `Money`, `Crosshair`, `ObserverCrosshair` |
| `damageType` | `Player` | `Damage`: `Fall`, `Burn`, `Freeze`, `Bullet`, … |

Полный список имён — типы в `as/flags.ts`. Семейства делаются из констант
AMXX с общим префиксом (`HIDEHUD_*`, `IN_*`, `EF_*`, `FL_*`, `DMG_*`);
генератор — `scripts/generate-flags.ts`.
