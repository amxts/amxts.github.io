## Описание плагина

```ts

```

То, что `amxx plugins` показывает в списке.

## Команды

```ts
server.addCommand("/hp", (player, args) => print(player, `${player.health} HP`));
server.addCommand("/kick", kick, { access: "Kick", description: "Kick a player" });
server.addCommand("amx_heal", heal);             // без слэша - команда консоли

function kick(player: Player, args: string[]) { ... }
```

Имя со `/` - команда в чате: её запускают и `say /hp`, и `say_team /hp`, а
строка в чат не попадает. Имя без слэша - команда консоли. `args` - слова
после имени: `/kick bob now` даёт `["bob", "now"]`. `access` - флаг админа
(`"Kick"`, `"Ban"`, …, редактор подсказывает); у кого его нет, тому команда
ничего не делает, а строка уходит в чат как обычно.

Типы у `player` и `args` в стрелке не нужны: их даёт `addCommand`.

Прежний `cmd("say /hp", sayHp, "KICK")` работает по-старому, с обработчиком
`id: number`; `server.addCommand` его заменяет.

Статус: проверено на сервере 2026-09-23.

Имя `"say <фраза>"` - строка чата без косой черты: `"say time"` срабатывает,
когда игрок пишет ровно "time" (в say или say_team), и `args` у неё нет.

### Команды сервера

```ts
server.addServerCommand("hns_reset", (args) => reset(args.length > 0 ? args[0] : "all"));
```

Команда консоли самого сервера: её набирают там, шлют по rcon или запускает
`server_cmd` другого плагина. Игрок её не набирает, поэтому обработчик
получает только `args` - слова после имени. Добавлять можно с верхнего уровня
файла: движку команда сообщается в `plugin_init`, потому что команда,
зарегистрированная при чтении файла (во время `plugin_natives`), роняла сервер,
когда её набирали. Что обработчик печатает, пока работает, уходит тому, кто
прислал команду: по rcon - в ответ rcon.

Статус: проверено на сервере 2026-09-24 - так запускается каждый набор
`bun run test:server`.

## События

```ts
server.addEventListener("putinserver", (event) => {
	print(event.player, "Добро пожаловать!");   // event.player — Player
});

server.addEventListener("disconnected", (event) => {
	console.log(`${event.player.name} вышел: ${event.reason}`);
});

server.addEventListener("cfg", (event) => loadSettings());   // конфиги прочитаны (plugin_cfg)

server.removeEventListener("impulse", onImpulse);             // та же функция, что добавляли
```

Как `addEventListener` в DOM. Имя события — строка, которую подсказывает
редактор (оба написания: `"putinserver"` и паунное `"client_putinserver"`);
опечатка — ошибка и в редакторе, и в сборке; обработчик получает тип своего
события сам — `(event) => ...` без аннотаций. Поля — аргументы форварда с
типами: номер игрока — `Player`, строка — `string`, флаг — `boolean`
(`event.dropped`).

Обработчик отдельной функцией называет тип события, это имя форварда:
`function onImpulse(event: ClientImpulseEvent) { ... }`.

Два ограничения компилятора под капотом:

- Имя пишется прямо в вызове: `server.addEventListener(name, ...)` с именем в
  переменной — ошибка сборки («an event name that is not written out as a
  string literal»).
- Обработчик может пользоваться всем, что объявлено на верхнем уровне файла,
  но не локальными переменными функции, внутри которой он написан, — замыканий
  в AssemblyScript нет. Сборка скажет `Not implemented: Closures` у этой
  переменной (перед этим — сбивающее «used before being assigned» про неё же).

## События игры

```ts
game.addEventListener("restartRound", (event) => console.log("a new round"));
game.addEventListener("takeDamage", (event) => {
	if (event.attacker.team == event.player.team) event.preventDefault();
});
```

Собственные функции игры - хукчейны reapi - это события на `game`, как события
сервера на `server`: тип по имени, ответ - вернуть значение, запретить -
`event.preventDefault()`. Подробно - в [Хукчейны](/ru/docs/hooks).

## Таймеры

```ts
const handle = setTimeout(onTick, 2000, 42);   // через 2 с, onTick(42)
setInterval(everySecond, 1000);
clearTimeout(handle);
```

Как в браузере, с одним отличием: третий аргумент — число, которое получит
обработчик (замыканий нет).

## Время и случайность

```ts
Date.now();                          // миллисекунды с 1970 года, число
new Date(Date.now()).getUTCHours();  // Date как в JavaScript, геттеры UTC
const start = performance.now();     // миллисекунды с точностью до микросекунды
Math.random();                       // 0 <= x < 1, при каждом запуске своё
```

Как в JavaScript: `Date` принимает и отдаёт число. Статус: проверено на
сервере 2026-09-23.

## Чат и консоль

```ts
print(id, "Only you see this");
print(0, "Everyone sees this");
print({ id, variant: "center" }, "Health restored!");   // "chat" | "center" | "console" | "notify"
console.log("to the server console");
```
