Статус: проверено на сервере 2026-09-23 - `game.addEventListener`, поля с
типами, `preventDefault()` (урон блокируется), post-обработчик читает
`event.result`, `removeEventListener`.

`canPlayerHearPlayer` игра спрашивает только при выключенном alltalk
(`sv_alltalk 0`); при включённом не спрашивает никого, и ответ там ни на что
не влияет. Чтобы заглушить игрока при любом alltalk - `player.muted`
([игроки](/ru/docs/players)).

Собственные функции игры - урон, спавн, бросок гранаты - это хукчейны reapi, и
плагин слушает их так же, как страница слушает DOM. Кто что слушает:

| объект | события | пример |
| --- | --- | --- |
| `server` | стандартные события AMX Mod X: игрок зашёл, вышел, смена карты | `server.addEventListener("putinserver", ...)` |
| `game` | функции игры (хукчейны reapi): урон, спавн, гранаты | `game.addEventListener("takeDamage", ...)` |
| `forward.subscribe` | форварды, которые шлют другие плагины | `roundEnd.subscribe(...)` |

```ts
import { game, CanPlayerHearPlayerEvent } from "~/facade";

// Ответить - вернуть значение. В pre-обработчике игра своё не считает.
game.addEventListener("canPlayerHearPlayer", (event) => event.listener.team == event.sender.team);

// Только запретить, без ответа.
game.addEventListener("traceAttack", (event) => {
	if (bits.get(event.player.id, BIT_PROTECTION)) event.preventDefault();
});

// Post: прочитать, что ответила игра, или вернуть замену.
game.addEventListener("flPlayerFallDamage", (event) => event.result / 2, true);

// Именованный обработчик - и снять его.
game.addEventListener("takeDamage", onTakeDamage);
game.removeEventListener("takeDamage", onTakeDamage);
```

Тип события берётся из имени: у `(event) => ...` не нужна аннотация, редактор
подсказывает имя и подчёркивает опечатку.

## Опции

Третий аргумент `post`: `true` - обработчик после функции игры, с
её результатом в `event.result`. Без него обработчик до функции и может её
остановить. `removeEventListener` принимает тот же `post`, с каким
обработчик добавляли.

## Что есть у события

| | |
| --- | --- |
| поля | аргументы цепочки с типами: `event.damage` - число, `event.sample` - строка, `event.damageType` - `Damage[]` |
| поля-сущности | `event.attacker`, `event.listener` - `Player`; предмет - `Weapon`; остальное - `Entity`. Номер - `.id`. Только чтение |
| `event.player` | игрок, о котором событие, - `Player`: `this` цепочки `CBasePlayer` и тот, кого reapi передаёт номером `index` (`playerSpawn`, `throwHeGrenade`, `playerBlind`, `showMenu`, ...) или `playerIndex` (`pmJump`, `pmDuck`, ...) - а не `new Player(event.index.id)` |
| `event.x = ...` | изменить аргумент до вызова функции игры (pre); `event.x` потом читает записанное |
| `return значение` | ответ цепочки: в pre - вместо игры (дальше не идёт); в post - поверх ответа игры |
| `event.preventDefault()` | функция игры не выполнится; ответ - значение по умолчанию (0 / false) |
| `event.stopImmediatePropagation()` | как `preventDefault()`, и обработчики после этого тоже не вызываются (`HC_BREAK`) |
| `event.result` | что ответила игра - в post-обработчике; только чтение |

Обработчик **либо всегда отвечает, либо никогда**: функция AssemblyScript не
может «иногда вернуть значение». Кто отвечает лишь в части случаев - ничего не
возвращает и блокирует `preventDefault()`, где нужно, или отвечает всегда,
повторяя для остальных правило игры. Тип ответа - тип цепочки (`boolean`,
`number`, `Player`/`Entity`): другой - ошибка сборки и ошибка в редакторе.
Цепочка, которая ничего не возвращает, ответа не принимает.

Обработчик не может использовать локальные переменные функции, в которой он
написан: замыканий в AssemblyScript нет («Not implemented: Closures»).
Переменные модуля и другие функции - можно.

## Перечисления и флаги - имена

Аргумент, у которого в reapi тип - перечисление Pawn, - юнион имён, а битовые
флаги - массив имён, как маска везде ([флаги](/ru/docs/flags)):

```ts
game.addEventListener("roundEnd", (event) => {
	if (event.reason == "targetSaved") event.preventDefault();   // ScenarioEventEndRound
	if (event.winner == "CT") ...                                 // WinStatus, как у game.endRound
});
game.addEventListener("showVguiMenu", (event) => {
	if (event.menu == "team") event.preventDefault();             // VGUIMenu
});
game.addEventListener("sendDeathMessage", (event) => {
	if (event.rarity.includes("Headshot")) ...                    // KillRarity
});
```

| событие | поле | Pawn | имена |
| --- | --- | --- | --- |
| `roundEnd` | `winner` | `WinStatus` | `RoundWinner`: `"TERRORIST"`, `"CT"`, `"draw"`, `"none"` |
| `roundEnd` | `reason` | `ScenarioEventEndRound` | `RoundEndReason`: `ROUND_*` в camelCase - `"ctsWin"`, `"terroristsWin"`, `"targetSaved"`, `"endDraw"`, `"gameRestart"`, `"none"`, ... |
| `roundEnd` | `delay` | `Float:tmDelay` | секунды |
| `canSwitchTeam` | `team` | `TeamName` | `Team` |
| `chooseTeam` | `choice` | `MenuChooseTeam` | `TeamChoice`: `"TERRORIST"`, `"CT"`, `"VIP"`, `"auto"`, `"SPECTATOR"` |
| `buyWeaponByWeaponId` | `weapon` | `WeaponIdType` | `WeaponKind`, как у `weapon.kind`: `"ak47"`, `"awp"`, ... |
| `addAccount` | `reason` | `RewardType` | `RewardReason`: `"roundBonus"`, `"enemyKilled"`, ... |
| `hasRestrictItem` | `restriction` | `ItemRestType` | `ItemRestriction`: `"buying"`, `"touched"`, `"equipped"` |
| `addResource` | `resourceType`, `resourceIndex` | `ResourceType_t`, `index` | `ResourceType`: `"sound"`, `"model"`, `"decal"`, `"generic"`, `"eventscript"`, ... |
| `onEvent` | `gameEvent` | `GameEventType` | `BotEvent`: `EVENT_*` в camelCase - `"playerDied"`, `"bombPlanted"`, ... |
| `showVguiMenu` | `menu` | `VGUIMenu` | `VguiMenu`: `"team"`, `"classT"`, `"classCT"`, `"buy"`, ... |
| `sendDeathMessage` | `flags` | `DeathMessageFlags` | `DeathMessageFlag[]`: `"Position"`, `"Assistant"`, `"KillRarity"` |
| `sendDeathMessage` | `rarity` | `KillRarity` | `KillRarity[]`: `"Headshot"`, `"NoScope"`, `"Penetrated"`, `"InAir"`, ... |
| `throwGrenade` | `velocity` | `Float:vecThrow[3]` | `Vector` |
| `hintMessageEx` | `displayIfHintsOff` | `bool:bOverride` | показывается и игроку, который отключил подсказки |

Присвоенное имя уходит в игру своим номером (`event.reason = "terroristsWin"`).
Номер, которому в include нет имени, читается как `"unknown"` (`"none"` у
`RoundWinner` и `WeaponKind`, `"UNASSIGNED"` у `Team`), а запись `"unknown"`
оставляет аргумент таким, каким его передала игра. Флаги, которых нет в
include, при записи массива остаются как были.

Имена и номера генератор берёт из include (`cssdk_const.inc`,
`reapi_*_const.inc`).

## Закончить раунд - `game.endRound`

```ts
game.endRound({ winner: "TERRORIST" });                  // победили террористы; следующий раунд через 5 с
game.endRound({ winner: "CT", delay: 3 });
game.endRound({ winner: "draw", message: "Никто не победил" });
game.endRound({ winner: "none", delay: 0.1, message: "" }); // тихий перезапуск
```

| опция | |
| --- | --- |
| `winner` | `"TERRORIST"`, `"CT"`, `"draw"` или `"none"` - кому очко, и сообщение и звук игры для такого конца |
| `delay` | секунд до следующего раунда; по умолчанию 5 |
| `message` | сообщение по центру (или токен `#CSTRIKE_`) вместо игрового; `""` - без сообщения |
| `sound` | радиозвук вместо игрового; `""` - без звука |
| `dispatch` | `true`: этот конец слышат обработчики `roundEnd` всех плагинов (и хуки `RG_RoundEnd` в Pawn), как слышат конец, который устроила сама игра. По умолчанию `false`, как у reapi: обработчик `roundEnd`, который снова заканчивает раунд, вызвал бы сам себя |

Под капотом - `rg_round_end` из reapi: `winner` - его `WinStatus` и
подходящий `ScenarioEventEndRound` (`ROUND_TERRORISTS_WIN`, `ROUND_CTS_WIN`,
`ROUND_END_DRAW`, `ROUND_NONE`).

## Имена

Имя события - имя reapi без класса, в camelCase; имя reapi - в подсказке:

| reapi | имя | событие |
| --- | --- | --- |
| `RG_CBasePlayer_TakeDamage` | `"takeDamage"` | `TakeDamageEvent` |
| `RG_CSGameRules_FlPlayerFallDamage` | `"flPlayerFallDamage"` | `FlPlayerFallDamageEvent` |
| `RH_SV_StartSound` | `"startSound"` | `StartSoundEvent` |
| `RG_CBasePlayer_Spawn` | `"playerSpawn"` | `PlayerSpawnEvent` |

Подсказки - из `scripts/docs/game.ts` (английский и русский,
`XEN_DOCS_LANG`), а где описания ещё нет - строка Description из самого reapi.

## Чего пока нет

Векторных аргументов (`Float:vecSrc[3]` и подобных) у событий нет - их 29, в
`fire_bullets`, `throw_*_grenade`, `trace_line` и ещё нескольких. Остальные
аргументы этих событий есть. Такой аргумент приходит в обработчик адресом в
памяти вызвавшего плагина, а прочитать оттуда три ячейки модуль пока не умеет
(`arg_text` читает строку).

Генератор: `scripts/generate-hooks.ts` → `as/hooks.ts` (`bun run generate`).
