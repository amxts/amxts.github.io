Статус: проверено на сервере 2026-09-23 - синхронные и промис-версии, файл
в 2090 символов, кириллица, отказ ENOENT для несуществующего файла. Без
сервера: `tests/plugin-natives.test.ts`.

Файлы так, как их читает Node:

```ts
import * as fs from "~/fs";

const text = fs.readFileSync("addons/amxmodx/configs/hns.ini");
if (text == null) return;                                  // файла нет

fs.writeFileSync("addons/amxmodx/data/last-map.txt", server.map);
fs.appendFileSync("addons/amxmodx/logs/rounds.log", `${server.map}\n`);

if (fs.existsSync("addons/amxmodx/configs/hns.ini")) ...
const maps = fs.readdirSync("maps");                       // ["de_dust2.bsp", ...] или null
```

И промисами, для `await`:

```ts
const text = await fs.readFile("addons/amxmodx/configs/hns.ini");
await fs.writeFile("addons/amxmodx/data/last-map.txt", server.map);

fs.readFile("missing.txt").catch((error) => console.log(error.message));
// ENOENT: no such file or directory, open 'missing.txt'
```

| синхронно | промисом | что делает |
| --- | --- | --- |
| `readFileSync(path)` → `string \| null` | `readFile(path)` → `Promise<string>` | весь файл текстом |
| `writeFileSync(path, text)` → `boolean` | `writeFile(path, text)` → `Promise<void>` | заменяет файл |
| `appendFileSync(path, text)` → `boolean` | `appendFile(path, text)` → `Promise<void>` | дописывает в конец, создаёт при надобности |
| `existsSync(path)` → `boolean` | `exists(path)` → `Promise<boolean>` | есть ли файл или папка |
| `readdirSync(path)` → `string[] \| null` | `readdir(path)` → `Promise<string[]>` | имена в папке, без `.` и `..` |

**Пути** — от папки игры (`cstrike/`), как у любого плагина AMX Mod X:
настройки в `addons/amxmodx/configs/`, данные в `addons/amxmodx/data/`. Если
сервер держит их в другом месте, `get_localinfo("amxx_configsdir")` и
`get_localinfo("amxx_datadir")` из `~/natives` скажут где (`get_configsdir()` в
Pawn — сток над тем же). Помощника для них пока нет: порт universal_config
покажет, нужен ли он.

**Текст** — UTF-8 в обе стороны, и файл читается целиком любого размера — без
буфера строки в 255 символов. Метка порядка байтов в начале остаётся, как в
Node.

**Ошибка** отличается от Node одним: исключений в AssemblyScript нет, поэтому
синхронные функции говорят о ней результатом — `null` у `readFileSync` и
`readdirSync`, `false` у `writeFileSync` и `appendFileSync` (например, папки
нет). Промисы отклоняются с `Error`, чьё сообщение начинается с `ENOENT`, как у
Node.

Работа синхронная — AMX Mod X читает файлы в потоке самого
сервера, — поэтому промис уже выполнен, когда функция вернулась, а `await` на
нём продолжает со следующей задачи.

Под капотом — файловые нативы AMX Mod X: `fopen`, `fread_blocks` (128 байт за
вызов), `fputs` (500 байт за вызов), `file_exists`, `dir_exists`, `open_dir` /
`next_file` — в `as/fs.ts`. В тесте поддельный сервер держит папку игры в
памяти: `server.writeFile(path, text)` до того, как плагин прочитает,
`server.file(path)` после того, как запишет, — см. [Тесты](/ru/docs/testing).
