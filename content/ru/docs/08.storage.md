Статус: проверено на сервере 2026-09-23 (get/set/has/delete, значение
пережило смену карты).

**Когда данные попадают на диск.** nVault держит изменения в памяти и пишет их
при смене карты или нормальном выключении сервера. Если сервер убит (падение,
`taskkill`), теряется всё, что записано после последней смены карты -
проверено: значение, записанное перед жёстким рестартом, пропало, а перед
`changelevel` - сохранилось.

```ts
import { Storage } from "~/facade";

const demos = new Storage("core_demo_counters");

const last = demos.get(auth);   // string | null — null, если ключа нет
demos.set(auth, "3");
if (demos.has(auth)) ...
demos.delete(auth);
```

Значения переживают смену карты и перезапуск сервера. Под капотом — nVault
из AMX Mod X: файл с именем хранилища в `addons/amxmodx/data/vault/`,
открывается при первом обращении.

Хранит строки, как и сам nVault. Число кладётся через `toString()`, читается
через `parseInt`. Длина значения при чтении — до 255 символов.
