`canPlayerHearPlayer` игра спрашивает только при выключенном alltalk
(`sv_alltalk 0`); при включённом не спрашивает никого, и ответ там ни на что
не влияет. Чтобы заглушить игрока при любом alltalk — `player.muted`
([игроки](/ru/docs/players)).

Собственные функции игры — урон, спавн, бросок гранаты — это хукчейны reapi, и
плагин слушает их так же, как страница слушает DOM. Кто что слушает:

| объект | события | пример |
| --- | --- | --- |
| `server` | стандартные события AMX Mod X: игрок зашёл, вышел, смена карты | `server.addEventListener("putinserver", ...)` |
| `game` | функции игры (хукчейны reapi): урон, спавн, гранаты | `game.addEventListener("takeDamage", ...)` |
| `forward.subscribe` | форварды, которые шлют другие плагины | `roundEnd.subscribe(...)` |

```ts twoslash locale-ru
declare const player: import("~/facade").Player;
// ---cut---
import { game, TakeDamageEvent } from "~/facade";

// Ответить - вернуть значение. В pre-обработчике игра своё не считает.
game.addEventListener("canPlayerHearPlayer", (event) => event.listener.team == event.sender.team);

// Только запретить, без ответа.
game.addEventListener("traceAttack", (event) => {
	if (event.attacker.team == event.player.team) event.preventDefault();
});

// Post: прочитать, что ответила игра, или вернуть замену.
game.addEventListener("flPlayerFallDamage", (event) => event.result / 2, true);

// Именованный обработчик - и снять его.
game.addEventListener("takeDamage", onTakeDamage);
game.removeEventListener("takeDamage", onTakeDamage);

function onTakeDamage(event: TakeDamageEvent) {
	event.damage = event.damage * 2;
}
```

Тип события берётся из имени: у `(event) => ...` не нужна аннотация, редактор
подсказывает имя и подчёркивает опечатку.

## Опции

Третий аргумент `post`: `true` — обработчик после функции игры, с
её результатом в `event.result`. Без него обработчик до функции и может её
остановить. `removeEventListener` принимает тот же `post`, с каким
обработчик добавляли.

## Что есть у события

| | |
| --- | --- |
| поля | аргументы цепочки с типами: `event.damage` — число, `event.sample` — строка, `event.damageType` — `Damage[]` |
| поля-сущности | `event.attacker`, `event.listener` — `Player`; предмет — `Weapon`; остальное — `Entity`. Номер — `.id`. Только чтение |
| `event.player` | игрок, о котором событие, — `Player`: `this` цепочки `CBasePlayer` и тот, кого reapi передаёт номером `index` (`playerSpawn`, `throwHeGrenade`, `playerBlind`, `showMenu`, ...) или `playerIndex` (`pmJump`, `pmDuck`, ...) — а не `new Player(event.index.id)` |
| `event.x = ...` | изменить аргумент до вызова функции игры (pre); `event.x` потом читает записанное |
| `return значение` | ответ цепочки: в pre — вместо игры (дальше не идёт); в post — поверх ответа игры |
| `event.preventDefault()` | функция игры не выполнится; ответ — значение по умолчанию (0 / false) |
| `event.stopImmediatePropagation()` | как `preventDefault()`, и обработчики после этого тоже не вызываются (`HC_BREAK`) |
| `event.result` | что ответила игра — в post-обработчике; только чтение |

Обработчик **либо всегда отвечает, либо никогда**: функция AssemblyScript не
может «иногда вернуть значение». Кто отвечает лишь в части случаев — ничего не
возвращает и блокирует `preventDefault()`, где нужно, или отвечает всегда,
повторяя для остальных правило игры. Тип ответа — тип цепочки (`boolean`,
`number`, `Player`/`Entity`): другой — ошибка сборки и ошибка в редакторе.
Цепочка, которая ничего не возвращает, ответа не принимает.

Обработчик может пользоваться переменными функции, в которой он написан, как
в JavaScript.

include, при записи массива остаются как были.

Имена и номера — собственные имена reapi, из `cssdk_const.inc` и
`reapi_*_const.inc`.

## Имена

Имя события — имя reapi без класса, в camelCase; имя reapi — в подсказке:

| reapi | имя | событие |
| --- | --- | --- |
| `RG_CBasePlayer_TakeDamage` | `"takeDamage"` | `TakeDamageEvent` |
| `RG_CSGameRules_FlPlayerFallDamage` | `"flPlayerFallDamage"` | `FlPlayerFallDamageEvent` |
| `RH_SV_StartSound` | `"startSound"` | `StartSoundEvent` |
| `RG_CBasePlayer_Spawn` | `"playerSpawn"` | `PlayerSpawnEvent` |

Подсказка описывает событие по-английски или по-русски (`AMXTS_DOCS_LANG=en|ru`
в `.env`), а где описания ещё нет, показывает строку Description из самого
reapi.

## Чего пока нет

Векторные аргументы (`Float:vecSrc[3]` и подобные, в `fireBullets`,
`throwHeGrenade`, `traceAttack` и ещё нескольких) читаются как `Vector`, но
изменить их пока нельзя: присваивание не компилируется.
