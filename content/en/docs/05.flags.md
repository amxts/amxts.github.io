Where Pawn has a bit mask, here there is an array of names:

```ts
player.hideHud = ["Money", "Timer"];                          // set
player.hideHud.push("Flashlight");                            // add
if (player.hideHud.includes("Money")) ...                     // check
player.hideHud = player.hideHud.filter(f => f != "Money");    // remove
player.hideHud = [];                                          // show everything

if (player.buttons.includes("Jump")) ...
if (player.flags.includes("OnGround")) ...
player.effects.push("NoDraw");
```

The editor suggests names and rejects a typo:
`Type '"Mony"' is not assignable to type 'HideHud'. Did you mean '"Money"'?`

To remove a flag, assign a filtered array: `pop` and `splice` don't write back
to the player, `push` does.

## Flag properties

| property | on | names |
| --- | --- | --- |
| `flags` | `Entity` | `EntityFlag`: `OnGround`, `Client`, `InWater`, `Fly`, `FakeClient`, … |
| `effects` | `Entity` | `Effect`: `NoDraw`, `DimLight`, `BrightLight`, `MuzzleFlash`, … |
| `buttons`, `oldButtons` | `Entity` | `Button`: `Attack`, `Jump`, `Duck`, `Forward`, `Reload`, `Attack2`, … |
| `hideHud`, `clientHideHud` | `Player` | `HideHud`: `Weapons`, `Flashlight`, `All`, `Health`, `Timer`, `Money`, `Crosshair`, `ObserverCrosshair` |
| `damageType` | `Player` | `Damage`: `Fall`, `Burn`, `Freeze`, `Bullet`, … |

The full list of names is the types in `as/flags.ts`. Families are built from
AMXX constants sharing a prefix (`HIDEHUD_*`, `IN_*`, `EF_*`, `FL_*`,
`DMG_*`); the generator is `scripts/generate-flags.ts`.
