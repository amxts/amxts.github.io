**When it reaches the disk.** nVault keeps changes in memory and writes them
out when the map changes or the server shuts down cleanly. A server killed
outright (a crash, `taskkill`) loses what was set since the last map change -
measured: a value set before a hard kill was gone, the same value set before
a `changelevel` survived.

```ts
import { Storage } from "~/facade";

const demos = new Storage("core_demo_counters");

const last = demos.get(auth);   // string | null — null if the key is missing
demos.set(auth, "3");
if (demos.has(auth)) ...
demos.delete(auth);
```

Values survive a map change and a server restart. Under the hood it is nVault
from AMX Mod X: a file named after the storage in
`addons/amxmodx/data/vault/`, opened on first access.

It stores strings, like nVault itself. Store a number with `toString()`, read
it with `parseInt`. A value is read up to 255 characters long.
